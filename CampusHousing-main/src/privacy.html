Roomwise privacy

Local prototype disclosure · October 24, 2026

Roomwise stores preferences, schedules, questions, notes, comparisons and saved decision briefs in this server's SQLite databases. This browser also caches drafts. Optional local accounts store salted password hashes and expiring sessions; no email recovery is provided. Default single-operator mode is intended for a private local machine.

Records can be exported or moved to recoverable trash under Data. Trash is retained until the operator performs a permanent purge. Moving to trash does not erase browser drafts, prior exports, comparison snapshots, related briefs or operator backups. Do not enter student IDs, banking details or other sensitive identifiers.

Google Maps requests leave your browser for Google. Nearby search sends the catalog property coordinates and selected category through this server to Google Places. It does not send your class schedule. If Google Routes is enabled, it receives origin/destination points, mode and transit arrival time. Google provider results are transient and excluded from saved decision briefs and training data. Google's Privacy Policy applies to Google services.

The default assistant uses local rules. If a model provider is enabled, the question, recent conversation and bounded selected housing evidence are sent to that configured model. Resident review text is not included; model training is a separate explicit workflow using authored synthetic examples.

No third-party analytics are configured. Application errors omit submitted schedules and passwords. Server access logs contain request paths; keep server logs private. Browser storage and exported files remain accessible to people who can access this browser profile or filesystem. This prototype has no hosted support operator or retention SLA.
