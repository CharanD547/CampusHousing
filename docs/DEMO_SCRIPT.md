# Two-minute Roomwise demo

Use actual screens and actual provider labels. Rehearse before recording. Do not substitute a rules response for a Gemma response without saying so.

| Time | Show | Explain |
|---|---|---|
| 0:00–0:15 | Explore | “Students see prices per room, per apartment and per installment. A cheap-looking number can hide a different billing basis and unknown fees.” |
| 0:15–0:35 | Search one property, inspect plans and source date | “Roomwise groups plans under one property. Asking figures retain their billing basis, range and dated source. A source check does not establish availability.” |
| 0:35–0:55 | Shortlist and compare two plans | “The backend computes known subtotals. Whole-unit splits are scenarios; usage-based charges and missing terms remain unresolved.” |
| 0:55–1:20 | Property → Ask the assistant about this plan | Ask: “Explain the asking price and billing basis. Which fees and lease facts should I confirm in writing?” Show the actual model alias, answer, source and limitation. Explain that Gemma interprets language while deterministic code owns the numbers. |
| 1:20–1:35 | Before you commit → Copy quote request | “The research becomes a concrete request for exact fees, dates, payment count and availability. Copying sends nothing to a landlord.” |
| 1:35–1:45 | Nearby map, miles selector and directions | “Students can investigate nearby essentials. Map points and straight-line distances are approximate; directions open separately.” |
| 1:45–2:00 | Saved brief and public repository/model card | “A brief freezes the evidence. Code, synthetic data and experiment reports are reusable. This is a working local prototype; we have not established adoption or real-world savings.” |

## If inference fails

Keep the fallback visible. Explain that unsupported model output is rejected and local research help remains available. Use a previously recorded real model response only if clearly identified as a recording from a particular run; never label a rules answer as Gemma.

## Impact validation task

Ask a consenting student to find a plan for a two-person household, identify room versus whole-unit billing, locate a source date, identify one unknown fee, and copy the quote request. Record completion and misunderstandings. Any measured time, participant quote or improvement claim belongs in the submission only after this task actually happens.
