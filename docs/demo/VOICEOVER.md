## Recording notes

This is an edited, paced browser walkthrough captured from actual visible Chrome interactions through Playwright locators. Browser frames were sampled at four frames per second and encoded as a 24-fps, 1280×720 H.264 MP4 lasting 90 seconds. Scene boundaries omit time between capture calls; it is not an uncut, native Playwright `recordVideo` session. No fabricated UI or model responses were inserted.

The separate demo instance used isolated storage, local Gemma v2, and Leaflet/OpenStreetMap with an actual nearby-grocery request. Google web services were disabled. The assistant response demonstrates actual model execution and labeling, not an independently validated answer-quality result. Prices are dated asking figures, not available lease quotes. Only synthetic demo questions and notes appear. The main user workspace was not modified.

The walkthrough covers the main product workflows; 90 seconds does not demonstrate every control, optional account flow, recovery action or provider configuration. The hidden Data page and removed schedule UI are not shown.
