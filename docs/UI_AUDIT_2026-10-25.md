## Reproduced issues and fixes

- **Google Maps escaped its panel and covered page content.** Reattaching a map reset the SDK container's inline positioning. The map now has a CSS containing block and clips its absolute children. Production Chrome confirmed no horizontal overflow before or after search rerenders, on desktop and phone.
- **Missed clicks and jumping pages.** Global smooth scrolling continued after route changes; background rerenders could replace an element during pointer activation. Navigation now jumps to its final position immediately, and rendering waits for pointer activation to finish. Previously missed mobile search/restart controls passed retesting.
- **Unsent text disappeared on updates.** New questions, chat drafts, home budget input and custom checklist drafts now survive unrelated rerenders. Consumed drafts clear on submission. Expanded disclosures stay open. These transient drafts deliberately do not survive a reload.
- **Nearby searches could remain stuck.** Changing category during a request invalidated the response but left the loading flag set. Category changes now cancel that pending state, clear old focus and allow the next request. A regression test covers this race.
- **Map jitter and displaced locations.** OSM markers are retained when inputs have not changed. Colliding price labels become compact pins instead of shifting their apparent geographic positions. Marker accessible names identify the property/business.
- **Phone overflow and navigation gaps.** Long research badges now wrap. All tested views fit phone/tablet/desktop widths. Mobile navigation includes the current guided step; Escape and selecting the current page close the menu. The debug button stays hidden during startup unless explicitly requested.
- **Historical briefs could crash.** Legacy conflict/insufficient verdicts remain renderable even though the active catalog policy was changed in pre-existing work. Saved displays now follow the captured selection order and convert source dates to Blacksburg time.
- **Directory links omitted newly added catalog entries.** Guide entries now resolve their derived catalog property, exposing their current plan/evidence/nearby page links.
- **Checklist ambiguity/staleness.** Repeated tasks identify their property; notes have descriptive labels. Saving a guide brief waits for the current checklist. The travel task no longer requires the removed class-schedule feature, and existing progress migrates when its title changes.
- **Misleading statuses.** Research counts count properties rather than plan rows. Disabled models show the local helper label. OSM/provider disclosure, offline status and recoverable-workspace-trash messages match actual behavior. Assistant summaries follow shortlist order, mark changed contexts stale and preserve failed questions for retry. The AI failure simulation now actually blocks the model request.

## Existing behavior preserved / limits

The pre-existing uncommitted comparison policy explicitly forces every candidate to `documented_fit`, moves conflicts and unknowns into notes, and tests that all 299 candidates match. I preserved that deliberate change rather than silently undoing it during a UI audit. Consequently, **the Criteria match badge is not a reliable constraint verdict** under that policy. Restoring meaningful fit/conflict/evidence verdicts is a separate product-behavior decision, and prevents claiming the whole product has zero issues.

The current pre-existing catalog contains 44 priced places; the guide directory retains 47 references. Three guide-only references are excluded by the current catalog-building policy. This audit did not invent prices or change that inclusion policy.

Google Places/Routes billing/access failures were not newly exercised; the free OSM path and actual browser SDK were. Optional account creation/login is not active in the tested UI mode; backend tests cover its boundaries. Not every external operator website or every possible failure combination was visited. No test suite proves absence of all bugs, nor establishes rental availability, complete costs, or universal model correctness.
